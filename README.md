# ☕ Starbucks Beverage Analysis Dashboard – Power BI Project

This Power BI dashboard provides an interactive analysis of **Starbucks beverages**, focusing on nutritional metrics such as calories, sugar, protein, caffeine, beverage categories, and preparation types.

## 🚀 Features

- 📊 Interactive beverage analysis
- 🔥 Average calories analysis
- 🍬 Average sugar analysis
- ☕ Average caffeine analysis
- 🥛 Protein range analysis
- 🧋 Beverage preparation analysis
- 📈 Beverage category comparison
- 🏆 Top 5 highest-caffeine beverages
- 🍩 Beverage category distribution
- 🔎 Interactive Protein Range & Beverage Prep filters

## 🧠 Technical Highlights

### 🔧 Data Transformation

- Cleaned and transformed beverage data using **Power Query**
- Prepared nutritional and category data for analysis
- Standardized data types and categorical fields

### 🧮 DAX Measures

Created custom DAX measures for:

- Total Beverages
- Average Calories
- Average Sugar
- Average Caffeine
- Category-wise analysis
- Top 5 highest-caffeine beverages

### 📊 Dashboard Visuals

- KPI Cards for key nutritional metrics
- Line Chart for average calories by category
- Bar Chart for average caffeine by category
- Donut Chart for beverage category distribution
- Top 5 highest-caffeine beverages
- Interactive slicers for Protein Range and Beverage Prep

## 💡 Key Insights

- **Average Calories:** 194.30
- **Average Sugar:** 33.02
- **Average Caffeine:** 81
- Identified the **Top 5 highest-caffeine beverages**
- Compared calorie and caffeine levels across beverage categories
